# Privacy Policy

1. **Data Collected** — Username and PIN code (authentication); Profile picture (optional); Posted content: video links, titles, descriptions, ratings, comments, chat messages; Group membership (list of members).
2. **Purpose of Collection** — This data is used exclusively for the operation of the application: authentication, displaying content shared within a group, and running the chat and watchlist features.
3. **Data Sharing** — No data is sold or shared with third parties for commercial or advertising purposes. Data is hosted by Supabase Inc., which acts as a technical data processor.
4. **Data Retention** — Data is retained for as long as the user account remains active. It is deleted upon user request or account deletion.
5. **User Rights (GDPR)** — In accordance with GDPR, users have the right to access, rectify, delete, and port their data. To exercise these rights, contact: reelrivals877@gmail.com.
6. **Security** — Data is protected through Supabase's security mechanisms (encryption in transit, secure authentication, group-restricted access rules — Row Level Security).
7. **Cookies / Trackers** — The application does not deploy any advertising cookies or third-party tracking scripts.
8. **Contact** — For any questions regarding this policy: reelrivals877@gmail.com
